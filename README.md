# Where2Go-Tourism-website

# 🌍 City Tourism Guide

An interactive tourism guide built with **Python (Streamlit)** that helps users explore the best tourist destinations, foods, travel options, and cultural highlights across major Indian cities.  
The project uses **Streamlit for the app framework**, **HTML + CSS for styling**, and integrates **video elements** for a more engaging experience.

---

## ✨ Features
- 📍 City selection interface covering 16+ popular Indian cities.  
- 🏛️ One-line highlights of top tourist attractions.  
- 🍲 Recommendations of famous local foods to try.  
- 🚖 Information on the best ways to travel within each city.  
- 🎉 Suggested months to visit based on festivals, affordability, and crowd levels.  
- 🎬 Integrated video support for an immersive travel experience.  
- 🎨 Enhanced UI with custom HTML + CSS styling.  

---

## 🛠️ Tech Stack
- **Framework:** [Streamlit](https://streamlit.io/)  
- **Language:** Python  
- **Frontend:** HTML, CSS  
- **Video Editing/Integration:** Streamlit video components
